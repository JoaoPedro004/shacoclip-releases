# Shaco Clip

Replay instantâneo e gravação de jogos para Windows 10/11 (NVIDIA, AMD, Intel ou sem placa de vídeo).

**Baixar:** abra [Releases](../../releases/latest) e baixe `ShacoClip-Setup-<versão>.exe`.

- Instala só para o seu usuário, sem administrador.
- Na primeira abertura, um assistente pergunta resolução, FPS, formato e áudio.
- F8 salva o replay; F9 começa/para uma gravação.
- O app avisa quando sai uma versão nova e atualiza com um clique.

O Windows pode mostrar "O Windows protegeu o computador" (o instalador não tem assinatura digital):
clique em "Mais informações" > "Executar assim mesmo".

Cada versão traz o arquivo `.sha256` com o hash do instalador (o app confere antes de instalar).
